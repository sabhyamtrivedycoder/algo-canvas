# 🚀 AlgoCanvas — Interactive Algorithm & Pathfinding Visualizer

> Real-time interactive visualizer for A* Pathfinding, Dijkstra, and Sorting Algorithms with WebAudio frequency feedback.  
> Engineered with ❤️ by **Sabhyam Trivedy** (14yo Founder & Software Engineer).

## 🌟 Key Features
- **100% Client-Side**: Zero backend latency, completely functional offline in modern browsers.
- **Modern Dark UI**: Engineered with responsive design, glassmorphism, and accessible contrast.
- **Fast & Zero Dependencies**: Lightweight architecture built for high performance.
